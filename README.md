# ⬡ CYBORG | Human × Machine Evolution


> **Pioneering the convergence of biological intelligence and artificial evolution. Building tomorrow's consciousness today.**

CYBORG is a premium, futuristic landing page designed to showcase advanced technology concepts like Neural Interfaces, Quantum Computing, and Autonomous Cybernetics. It features a highly interactive glassmorphism UI, custom micro-interactions, and high-performance vanilla JavaScript animations.

## ✨ Features

- **Custom Cybernetic Cursor**: A magnetic, multi-layered cursor that interacts fluidly with clickable elements.
- **Dynamic Backgrounds**: Parallax mouse-light tracking and an animated grid overlay create deep, immersive environments.
- **Scroll Orchestration**: Elements sequentially reveal themselves as you scroll using modern `IntersectionObserver` techniques.
- **Data Visualization**: Animated stat counters and progress bars that calculate physical physics (`easeOutExpo`) when scrolled into view.
- **Glassmorphism 2.0 UI**: Blurry, frosted-glass feature cards with responsive glowing edges and SVGs that react to user interaction.
- **Responsive Design**: Flawlessly adapts to any screen size, complete with a mobile-optimized side-drawer navigation.
- **Simulated Form Transmissions**: The contact form features network delay simulations and a beautiful success overlay.

## 🚀 Technology Stack

Built purely with modern, vanilla web technologies—no frameworks, no bloat.

- **HTML5**: Semantic, accessible structure and SEO-optimized meta tags.
- **CSS3**: CSS Variables for easy theming, Flexbox/Grid layouts, cubic-bezier animations, and `backdrop-filter` for glass effects.
- **Vanilla JavaScript (ES6)**: `requestAnimationFrame` for buttery-smooth 60fps animations and `IntersectionObserver` for performant scroll-tracking.
- **Google Fonts**: Utilizes `Orbitron` (headings), `Rajdhani` (body), and `Share Tech Mono` (data/UI) for a distinctly cyber-tech aesthetic.
